Sécurité

Protection contre les sites dangereux
Avertit avant d’ouvrir un site d’hameçonnage ou de logiciels malveillants, et bloque leurs téléchargements. Les adresses visitées ne quittent pas l’ordinateur.

Démarrage et arrière-plan

Garder Lasco ouvert dans la barre des menus
Fermer la fenêtre la masque : les agents, les validations et les notifications continuent. ⌘Q quitte Lasco.
Ouvrir Lasco à l’ouverture de session
Lasco démarre avec l’ordinateur.
À autoriser dans Réglages Système > Général > Ouverture.

Raccourcis clavier

Disponibles partout, même quand Lasco est masqué. Cliquez sur un raccourci puis tapez la nouvelle combinaison (avec ⌘, ⌃ ou ⌥). Échap annule.

Recherches tapées dans la barre d’adresse des onglets de Lasco.

Moteur de recherche par défaut
Utilisé quand le texte tapé n’est pas une adresse, et par « Rechercher » du clic droit.

Recherche sur les sites

Tapez le raccourci d’un site dans la barre d’adresse (par exemple « wikipedia.org ») puis Tab ou Espace pour chercher directement sur ce site.

Ajouter les sites visités qui proposent une recherche
Comme Chrome : un site qui déclare son moteur (OpenSearch) devient un raccourci. Les sites déjà ajoutés restent.

Moteurs ajoutés

Sites repérés

Fichiers téléchargés depuis les onglets web et depuis Lasco (exports CSV, PDF…). La liste est dans le menu ☰ du navigateur > Téléchargements.

Emplacement

Mettre en veille les onglets inactifs
Onglets web et pages de Lasco. Jamais l’onglet affiché, un onglet qui joue du son, en plein écran, en appel, piloté par un agent, avec une saisie en cours, ni Lasco Code.

Opérations des agents IA sur cet ordinateur, après votre confirmation. Désactivé par défaut. Sans lien avec la machine virtuelle.

Opérations sur l’hôte
Déplacer, copier, renommer des fichiers et créer des dossiers.
Commandes shell
Commandes dans votre shell, avec vos droits. Chacune est affichée et confirmée, sauf « Toujours autoriser » (préfixe dans un dossier). Les commandes composées ou sensibles (suppression, sudo, réseau, interpréteurs…) sont confirmées à chaque fois.
Projets de code (Lasco Code)
Lecture des projets git ouverts dans Lasco Code (jamais .env, clés) et propositions de modifications, confirmées sauf « Toujours autoriser dans ce projet ».
Harnais de code
Claude Code, Codex, Cursor ou Mistral Vibe sur un projet ouvert dans Lasco Code. Chaque lancement est confirmé. Connectez-vous vous-même à chaque harnais dans un terminal.
