Cet ordinateur : opérations des agents IA

Permet aux agents de déplacer, copier, renommer des fichiers, créer des dossiers et, si vous l’activez, exécuter des commandes sur cet ordinateur, après votre confirmation. Désactivé par défaut. Sans lien avec la machine virtuelle.

Commandes shell : l’agent peut exécuter des commandes dans votre shell, avec vos droits. Chaque commande est affichée et confirmée, sauf celles couvertes par une autorisation « Toujours autoriser » (préfixe de commande dans un dossier). Les commandes composées ou sensibles (suppression, sudo, réseau, interpréteurs…) sont confirmées à chaque fois.

Projets de code (Lasco Code) : l’agent peut lire les projets git que vous avez ouverts dans Lasco Code (sauf fichiers sensibles : .env, clés) et y proposer des créations ou modifications de fichiers. Chaque modification est affichée et confirmée, sauf « Toujours autoriser dans ce projet ».

Harnais de code : l’agent peut lancer Claude Code, Codex, Cursor ou Mistral Vibe sur un projet ouvert dans Lasco Code. Chaque lancement est confirmé, sauf « Toujours autoriser » pour ce projet. Connectez-vous vous-même à chaque harnais dans un terminal.
